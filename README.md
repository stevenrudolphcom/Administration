# Administration

Sammlung von Skripten fuer die lokale Windows- und Linux-Administration.

## Windows

- `Windows\get_windows_os_key.ps1` zeigt den aus Windows auslesbaren Product Key an.
- `Windows\update_all_winget_packages.ps1` aktualisiert installierte Pakete mit Winget und schreibt Protokolle unter `%LOCALAPPDATA%\WingetAutoUpdate`.

## Linux Debian

Linux-Administrationsskripte und Anleitungen befinden sich in den jeweiligen Linux-Unterordnern.
